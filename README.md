# 核芯弹射 · COREBOUND

一款可以在浏览器中玩的物理弹球 × Incremental Game。用反向拖拽发射小球，在密集矿石中开出通道；研究分裂、链爆、自动引航、跃迁、星阵与稀有宝库，把一次连击变成破坏与收入的连锁反应。

## 运行

本地开发地址：**http://127.0.0.1:5173/**。

Windows 可双击 **启动游戏.cmd**。需要 Node.js 20.19+ 或 22.12+；本项目已在 Node.js 24 上运行验证。

```sh
npm install
npm run dev
```

构建静态网页：

```sh
npm run build
npm run preview
```

生产文件位于 `dist/`。游戏没有后端，不依赖在线图片或字体，静态文件加载后即可游玩。

GitHub Pages 目标地址：**https://fiiction.github.io/physicsincremental/**。仓库名称为 `fiiction/physicsincremental`，在仓库 Settings → Pages 中将 Source 设为 GitHub Actions，推送 `main` 分支后由 `.github/workflows/deploy.yml` 自动构建发布。构建命令配置了对应的子目录路径；生产预览使用 `npm run preview -- --base=/physicsincremental/`。

## 操作

- 在圆球附近按住，向目标反方向拖拽后松开；拖得越远，动能越多。
- 方向键瞄准，空格满力发射；A 切换已解锁的自动引航；P 暂停。
- 停球后继续从原位置发射。每局初始 5 发；矿晶立即入账，可以停球后提前结算。
- 普通方块只产矿晶；金色◇宝箱必得普通道具，王冠宝库必得专属稀有强化。研究透视后可见内容。深色 ◆ 是核心，红色 ✹ 会爆破，满层强化转为矿晶。
- 方块边长为格距的 0.9；中心空洞边长随损伤从 0 增至 0.8，受击时短促位移回弹。两个比例均可配置。
- 普通强化每种最多 3 层，稀有强化每种 1 层；都从下一发起生效、本局持续。用球体材质、卫星、尾迹和实际机制动作表现，新局重新积累。
- 3 连击起在击破位置显示数字。10 连击起开启固定半径 0.9 的斜向色散；色相强度在 10 / 20 / 40 / 80 / 100 连击时分别为 0 / 0.1 / 0.2 / 0.3 / 0.325，每单位强度旋转 180°。增强用 0.18 秒平滑接入，减弱用 0.75 秒渐退，连击跳增或快速开始下一发都从当前画面连续过渡。研究「连击铸币」后，每跨 10 连击有额外矿晶流向钱包。
- 清除本关规定比例的原生矿石后，中心唤醒巨型旋转首领，用本局剩余弹射挑战。击败后播放 1.4 秒解体仪式并直接结算；主线关可领取突破核心与奖励，再选择下一站。局内生成的额外宝箱不计唤醒进度。
- 顶部「科技」打开完整科技星图，47 个节点与真实前置连线始终在同一张图上，五色区分核心、联动、星阵、宝库与终局。默认全览，可拖拽、滚轮或双指缩放，一键全幅复位。轻点节点查看浮动详情与整条前置链，前置按钮可定位节点；升级点亮等级环，满级亮环闭合，购买后保留镜头位置。
- 点击顶部常显的「选关」，或结算页的「选关」，可进入已解锁区域刷钱。「选关」与已解锁的「自动」使用章节淡色高亮。图鉴记录道具与核心；星阵、宝库和终局保留隔离试玩，退出恢复正式进度与原暂停状态。
- 设置中分别开关、调节音效与背景音乐；背景音乐默认关闭。还可管理震动、碎片和「柔和特效」，后者关闭全屏染色并减少动态反馈。

## 已包含

五个机制递进的章节与五位几何首领、47 个科技节点、7 种普通道具、3 种稀有强化、3 种永久突破核心、个人纪录与可升级挂机。核心分别解锁耗能返航切割、锚点光弦、真实弹簧地形；集齐后下一周目可让返航与弹簧网络联动。第三章引入跨矿层传送门，第四章引入十字光束，第五章「终光圣殿」每跨 40 连击在后续真实碰撞时释放斜交裁光，附带生命剥离。

首领把开矿后的局内强化集中到一个终点：巨型方块按真实碰撞角度旋转，色谱层位置固定，白色方孔的边长随损伤比例扩大。首领激活后，每击破一个小方块削去其当前生命的 1%，只能削弱，不能击杀；主球或分球必须真实撞中首领，才能造成大额伤害并完成最后一击。光束、雷链、裂隙、星阵等机制通过清理小方块参与削弱，不直接伤害首领。清场时有细线与方粒流向首领，直接撞击才产生方向回弹。

失败会显示剩余生命比例，已经获得的矿晶保留；研究科技后，下一局重新开矿并召出满血首领。节奏目标是首次见到首领后约 3 局挑战中完成成长与击败，不设置强制失败、按玩家能力调整生命或跨局继承残血。`boss.clearDamageFraction` 控制清场削弱比例，`directDamageMultiplier` 控制真实撞击倍率；前三区为 1，第四区为 8，第五区为 48。生命、唤醒门槛和旋转参数保持章节固定配置。

王冠宝库需科技解锁，每图初始仅 2 座，位于第六环及以外；研究后最多 5 座，并可把最近目标移至第三环。独有的「白热超载」放大整发伤害，「跃迁雷链」跳击最多 6 块矿石，「虚空裂隙」留下半径 96、持续 1.8 秒的侵蚀区域。新联动让宝库增加连击并播种普通箱、铸币触发震波并给星阵充能、分球释放雷链、返航到锚点后展开裂隙。普通箱科技的密度上限降低，为稀有目标留出注意力。

每局重新生成连贯矿脉纹样、宝箱分布与传送门位置。宝箱内容在地图生成时确定，宝箱相关科技增加新地图的生成密度；自动与手动开采都兑现同一内容。各区域分别保存开采记录；刷旧关击败首领可赢下本局，但不会重复领取主线突破奖励。新周目保留全部区域开放，主线仍按顺序推进。

12 个后期节点使用「分球震波」「分球返航」「返航布星」等直白名称，让分球获得范围攻击、光弦、返航和弹簧补能。「三点星阵」由发射点与碰撞点围合矿层，每撞、每击破均可供能，满 10 格后坍缩切割。连击、分球、弹簧、返航和光束继续接入星阵；「星阵齐射」在坍缩后释放追踪光矛，攻击锁定的残余矿石。

场内会显示能量从哪里进入星阵、哪些方块即将受击，以及坍缩实际命中或击破数。每种联动有对应的几何动作，首次触发短暂显示名称；选中科技节点可看局部演示，也可进入完整星阵试玩。

后期主要联动可升至 6–8 级：分球光弦与回切最多覆盖每发前 16 球，星阵齐射最多 12 束，连击充能 4 / 6 级分别增加一次每发坍缩机会。四个 6 级终局节点把激光接入雷链、让裂隙消退后坍缩、让星阵坍缩留下持续裂隙，并让终光追加最多 14 束追猎光矛。新攻击复用真实目标和延时队列，保留冷却、场地与时间预算。

挂机自动完成瞄准、发射、重新开局，隐藏标签时由独立 Worker 接管同一模拟。初始矿晶收益 20%、等待 5 秒，后续科技提升收益并缩短等待；宝箱掉落无额外惩罚。浏览器彻底冻结时恢复后补算经过的时间；关闭或丢弃页面只保留最近检查点，不结算关闭后的离线收益。主线完成时等待玩家领取核心并选择下一站；等待选关期间不会自动开局或推进，刷新后仍保留此状态。旧关可持续开采。

基础伤害为首章内层普通矿石生命的 60%，初始单发保持约 2–3 次反弹的弱开局。速度以动能平方根计算，升级后可达到 3,200 的上限；滚动阻力与高速二次阻力控制续航，普通飞行在 14 秒内结束，最后 0.8 秒平滑缓停。每局生成最多一份电池，总弹射不超过 9 发。各章节生命倍率为 1 / 40 / 10,000 / 1,600,000 / 100,000,000；基础环表最外环倍率为 360，配合最高 4.85 倍的图案层级，让同一矿场的内外层形成更长的开拓过程。第五章新局使用 1.30 次幂的环成长，第九环再加固约 5.85 倍；入口生命保持，额外生命不同时放大百分比攻击。前四关与进行中的旧局保留原规则。29 项机制与宝库科技重排价格，初次研究后继续向中高等级积累；四个终局节点逐级价格倍率为 8–9，48 级力量与 24 级动能的价格保持。

五章均使用原创 12 级色谱，图案生命取色随连续场变化：蓝紫花瓣、暖色双圆、青绿旋流、紫色切面、金色偏心方庭。艺术参考与具体转译见 [美术方向](docs/ART_DIRECTION.md)。

## 修改数值

`src/data/balance.json` 是主要内容和数值入口：

| 字段 | 内容 |
|---|---|
| `physics` | 方块与空洞比例、动能、滚动减速、高速二次阻力、碰撞损耗、速度上限、末段缓停与球数 |
| `economy` | 初始弹射、宝箱生成率、连击收益、挂机收益与等待 |
| `mechanics` | 分裂、冲击、穿透、爆破、传送与光束参数 |
| `relicMechanics` | 回返、光弦、弹簧与三核合相参数 |
| `combinations` / `constellation` | 后期联动、三角几何、充能、坍缩与追踪光矛、触发上限 |
| `combo` / `elite` | 连击铸币、震爆、终光裁切；高级宝库数量与位置、三种稀有强化及联动 |
| `lateGame` | 光束引雷、裂隙坍缩、星阵裂隙与终光追击的倍率、冷却与数量 |
| `boss` / `chapters[].boss` | 清场削弱比例、直接撞击倍率、召唤与胜利时长、粒子、色谱层与回弹；各章生命、旋转尺寸与速度、唤醒比例 |
| `growth` | 科技、遗物、周目成长幅度 |
| `generation` | 深层宝箱起始环、纹样相位变化、传送门出口距离与变体 |
| `ringHP` / `tierHP` / `chapters` | 外环及图案等级生命、章节倍率与 `ringHPExponent` 外环加固、配色、补给、单局清场比例与奖励 |
| `upgrades` / `drops` / `relics` | 科技、道具、遗物；`viewGroup` 星图分支配色、`previewCue` 因果句与 `levelDescriptions` 分级说明 |
| `previews` / `effects` | 独立试玩配置、粒子、拖尾、普通/稀有掉落尺寸与停留、Combo 色相增长、固定色散强度与两通道渐退 |

声音事件、采样、音量、音高、淡入淡出与并发限制集中在 `src/data/audio.json`；本地素材出处及许可见 [音频设计](docs/AUDIO.md)。

数值效果与描述分别存放在同一数据文件中；调整效果时也要更新对应说明。19×19、608×608 是当前关卡几何约定，修改格数或场地尺寸需要同时调整渲染与关键方块布局。

## 技术结构

- Vite + 原生 JavaScript ES modules：无界面框架或后端负担。
- PixiJS 8：WebGL 渲染、图形批处理、1,600 个 GPU 粒子池；Web Audio 播放本地采样与环境音乐。
- `src/game.js`：无 DOM、无渲染依赖的确定性模拟。120 Hz 固定步长、普通矿石轴对齐矩形碰撞、首领旋转矩形碰撞、空间格索引。游戏内挂机与开发测试复用 `autoAngle()` / `launch()` / `tick()`。
- `src/audio.js` / `src/data/audio.json`：事件音效、背景音乐、独立音量、并发限制与淡入淡出；素材及许可见 [音频设计](docs/AUDIO.md)。
- `src/renderer.js`：几何画面、粒子、镜头、输入与音频事件接入。随机视觉效果不影响物理随机序列。
- `src/main.js`：界面、持久化、试玩、可选 WebMCP。
- `src/research-view.js`：完整科技星图、真实前置连线、等级环、节点定位与拖拽缩放镜头。
- `src/idle.js` / `src/idle-worker.js`：经过时间补算、后台模拟；前后台交接只允许一方推进。

## 玩家循环检查

```sh
npm run playtest
# 也可以传入 1–200 个开局样本
npm run playtest -- 60
# 探索、选关、随机地图与宝箱规则
node scripts/exploration-check.mjs
# 首领碰撞、失败重置与旧存档兼容
node scripts/boss-check.mjs
# 首领受击画面与音频生命周期
node scripts/boss-feedback-check.mjs
node scripts/audio-check.mjs
```

默认采用 30 个种子，不创建浏览器或 GPU，按真实规则完成自动开采、购买、结算和五章推进，保存 `reports/playtest.json`。购买策略先研究一级力量、动能与挂机，再购买当前可用且最便宜的科技；逐发记录破坏数、强化层数、时长和机制触发。

原有检查覆盖首发强度与平滑停球、旧局清场与余弹兼容、电池与球数上限、暂停和飞行存档、挂机续局、真实 Worker 延迟唤醒交接、全科技压力，以及星阵蓄力与光矛队列续存、裁边几何、返航布星、次数与时限、光矛改锁与防递归、激光冷却。首领版本还需评估首次相遇后的逐局损伤、升级与击败节奏；最新结果见 `docs/STATUS.md`。自动游玩不能替代对瞄准手感、反馈和成长节奏的实际体验判断。

`exploration-check.mjs` 检查旧关挂机、保存后返回主线、锁关与重复奖励保护，以及地图随机性、传送门续存、普通与高级箱的科技门槛、固定内容、稀有数量/位置、播种上限和普通方块不掉道具。

`boss-check.mjs` 检查首领清场削弱与直接撞击的区别、固定生命、真实碰撞、高速防穿透、飞行保存恢复、失败后满血重召、召唤不补弹射，以及旧局领奖和等待选关的兼容性。当前规则的成长抽样见 `reports/boss-contact-balance.json`；旧版报告不能代替当前规则的节奏结果。

详细设计见 `docs/DESIGN.md`，验证与实现状态见 `docs/STATUS.md`。

## 存档与日志

浏览器本地存档键：`corebound.save.v1`；重置／导入前备份：`corebound.save.v1.backup`。每约 2 秒保存，并在关键事件与离开页面时保存。保留最高解锁区域、主线位置、各关累计进度、当前地图纹样、宝箱内容和传送门位置；球体、返航、强化、星阵、追踪光矛、裂隙、连击领奖档位、首领状态及暂停/挂机计时也可续接。突破后等待选关的状态单独保存，刷新不会重复领奖，也不会提前进入新区。没有 `run.bossVersion` 的进行中旧局保留该局原突破规则，下一局开始采用首领规则。旧四区转生档会开放新增第五区，保留当前球位、矿晶和科技；新版地图配置从新局生效。

最近 30 局的统计保存在存档中，最近 200 条事件可从「设置 → 日志」查看或下载 JSON。首领战分别记录清场削弱伤害与方块数（`bossChipDamage` / `bossChipKills`）、直接撞击伤害与次数（`bossDirectDamage` / `bossDirectHits`）。浏览器控制台以 `[COREBOUND]` 显示核心突破、升级、结算的关键事件。没有遥测或第三方上传。

在支持 WebMCP 的浏览器中提供 `read_game_state`、`launch_ball`、`start_mechanic_preview`、`leave_mechanic_preview`。状态读取包含首领阶段、生命、尺寸与旋转角度。不支持时不影响游戏；测试可直接导入纯逻辑模块。
