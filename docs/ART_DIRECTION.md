# 核芯弹射：矿场与连击的美术方向

## 参考与转译

本轮参考了三组博物馆资料。游戏的色谱和图案均由配置与数学场重新设计，没有从原画吸取色号，也没有把网上的作品图片装入游戏。

- Sonia Delaunay 的《Prismes électriques (couleurs simultanées)》（1914）以圆盘、相邻色区和重复弧线形成光感与运动。第二章把这种色块组织转为两个偏心圆共同影响的连续暖色矿脉；画面静止时也有相互推挤的方向。[蓬皮杜中心作品资料](https://www.centrepompidou.fr/fr/ressources/oeuvre/zS28bfR)
- Josef Albers 的《Homage to the Square: With Rays》（1959）为套叠方形与色彩关系提供参考。第五章用偏离中心的方形距离场组织金、赭、玫瑰与靛色，保留方块媒介本身的秩序。[大都会艺术博物馆作品资料](https://www.metmuseum.org/art/collection/search/489056)
- Hilma af Klint 的展览作品为有机轮廓和几何形态之间的组合提供视觉方向。第一章采用花瓣起伏，第三章采用旋流，第四章收紧为对角切面；这些是本项目对参考作品的构图转译。[古根海姆《Paintings for the Future》展览资料](https://www.guggenheim.org/exhibition/hilma-af-klint)

## 五个原创色场

每关使用 12 个可编辑色阶，浅色在出生区附近起步，整体向深色外圈推进。层级由连续图案场决定，同一环不再只有一种颜色；每局旋转、镜像与微调相位，保持结构连贯。具体颜色存放于 `src/data/balance.json` 的 `chapters[].palette`。

| 关卡 | 色谱方向 | 图案与作用 |
|---|---|---|
| 初生矿庭 | 冰蓝 → 天蓝 → 紫蓝 → 暗梅紫 | 四瓣形缓慢起伏；让弱开局保持明亮、安静 |
| 余烬铸造厂 | 杏黄 → 橘红 → 玫瑰 → 暗紫红 | 双圆相交形成暖色层；爆破红仍能从背景分离 |
| 折跃织井 | 浅黄绿 → 薄荷 → 青绿 → 蓝灰 | 旋流围绕出生区展开；与双向传送的空间位移呼应 |
| 共振棱镜 | 浅丁香 → 紫罗兰 → 靛紫 → 墨紫 | 对角切面；为横纵激光提供清楚的几何参照 |
| 终光圣殿 | 乳金 → 蜂蜜 → 赭玫瑰 → 夜靛 | 偏心套叠方庭；斜交裁光横跨安定的方形层次 |

纯白背景、0.9 格边长、线性方孔伤痕保持一致。普通矿石用色谱，普通宝箱用金色◇，高级宝库用更稀疏的王冠纹样与外框；透视只替换内容标记，保留箱种轮廓。第五章新局的外环加固仍使用原有色谱与方孔伤痕，方孔依据加固后的真实损伤比例变化，额外生命不增加百分比攻击的伤害基数。重要性由稀疏度、几何差异和实际动作共同表达，不依赖大段文字。

## 首领：整片矿脉的几何核心

每章完成规定的开采比例后，中心召出一枚巨型旋转方体。苍蓝方心、余烬王冠、折跃方舟、棱镜执政与终光原核分别复用本章色谱，深色外缘与较浅内核通过套叠方形形成层次，不引入贴图、裂纹或额外美术风格。方体尺寸和角度直接读取真实旋转碰撞体；受击回弹只短暂偏移画面，物理位置保持原位。

首领以七层为基础，后续章节增加套叠层、外框与卫星数量，逐渐强化体量感。色阶层的尺寸固定，内核避开接近白色的最浅颜色；唯一纯白的方孔按真实损伤比例线性扩大，边长为 `首领边长 × boss.visual.hollowMax × 损伤比例`，当前最大比例为 0.86。完整方体与受伤空洞因而有清楚区别，外缘始终保留色彩。

主球或分球真实撞中时，方体沿受力方向短促退让并回弹，同时加厚旋转外缘。`boss.visual.punchDistance` 为 9 单位、`punchDuration` 为 0.26 秒；位移由衰减波形控制，实际峰值小于配置幅度。同一批命中采用最强直接碰撞的方向；一次回弹完成前不重启或反向，密集攻击也不会让首领瞬移或持续抖动。没有生命数字或闪白，上方细生命条保留损伤进度参照。

清理小方块对首领造成当前生命 1% 的削弱时，从击破位置向首领拉出短暂细线，少量小方粒沿线流动；生命条与方孔体现真实损伤，首领本体不产生位置回弹。清场的轻量反馈与碰撞重击形成层次，让玩家辨认「削弱」和「击破」。出场字幕短暂提示「清场削弱 · 撞击击破」，细节规则收在首领 HUD 的悬停说明中。

出场用层层方框朝中心聚合，场地边缘仅保留淡章色收束线，低沉音色建立重量。存活时外框反向慢转，少量方形卫星与向心短线表现吸聚；损伤跨过阶段时产生一次局部几何重拍。背景始终纯白，外框和流线使用低透明度，球体与弹道绘制在其上。

击败时实体立即消失，色层先向内收束，再反向旋转剥离并散成池化方形碎片。画面保留 1.4 秒胜利停顿后进入结算，剩余弹射无需继续用完。失败页用方孔轮廓和剩余生命比例说明挑战差距；下一局重新召出满血首领，伤痕不跨局继承。

正式挑战的节奏目标是首次相遇后约三局的「挑战 → 升级 → 再挑战」，并非固定通关次数。主要画面只出现短暂出场/胜利字幕、名称与细生命条，避免让首领变成新的说明面板。

## 连击与稀有强化

Combo 从 3 起仅在实际增加计数的击破位置显示并淡出，固定角落数字退回无障碍状态。色相由 `effectStrength` 驱动：10 / 20 / 40 / 80 / 100 连击的目标强度为 0 / 0.1 / 0.2 / 0.3 / 0.325，区间连续相接，没有倍数节点的额外跳增。色相按强度 × 180° 旋转，20 连击的强度 0.1 对应 18°。色散在 10 连击开启后保持固定强度 0.3、半径 0.9，清晰的矿石边缘不再因高连击持续扩散；每发随机取 30°–60° 斜角。先色散、再对其结果改变色相，不叠加无关的色相摆动。两种效果增强时用 0.18 秒二次缓出接入，减弱时用 0.75 秒退去；目标改变或快速开始下一发，都从当前画面连续重定向，两者归零后关闭。方块和拾取图标按可见像素居中，避免字体留白偏移。铸币产生金色脉冲、具体收益与飞向钱包的矿晶，让「击破 → 连击 → 收入」成为可跟随的运动。

高级箱开出道具时，图标比普通掉落更大、停留更久。白热超载改变球体与尾迹热感；雷链明确连接实际目标；裂隙留下持续脉冲的区域，并在真实伤害时反馈。所有表现从逻辑事件读取位置、范围和目标，不凭装饰制造命中。

终局联动使用已有几何语言的明确变化：光束引雷在交点接出青色链条，裂隙到期先收束再展开紫环，星阵裂隙有持续三角核心，终光追击从裁光端点发出金色追踪光矛。

科技界面是一张完整的 47 节点星图，所有节点与真实前置连线始终存在。五种分支色只区分系统方向，已点亮的节点与线路共同显露成长规模。默认全览，用拖拽、滚轮或双指缩放接近局部；选中节点突出整条前置链，前置按钮可直接定位。节点等级环逐次填满，满级形成闭合亮环；购买时单次扩散，镜头保持原位，使每次研究都成为整幅图上可见的积累。浮动详情与三个独立试玩入口保留，说明只在选中后出现。

顶部「选关」「科技」用常显文字和轻描边提供清楚入口，其余菜单图标保持轻量；窄屏把钱包放在单独的薄行，避免挤压主要操作。选关使用独立的区域路线图，也可从结算页直接进入。各区域以自身色谱与矿脉图案区分，只保留名称、机制和进入状态；图鉴继续承担发现与试玩。突破领取核心与奖励后，画面停留在「选择下一站」，让新区开放与玩家确认前往成为两个清楚的动作。

## 动效约束

全屏效果使用缓变的颜色与有限像素偏移，不采用黑白反转、快速反色或高频明暗闪烁。菜单和暂停时退去全屏效果，保证文字和瞄准参照清楚。「柔和特效」关闭全屏染色并减少长距离动态反馈；首领取消受击位置回弹、向心流线与摇动，减少聚合与解体位移及粒子数，保留白色方孔及边缘反馈。首领实体继续准确显示物理旋转，暂停时其回弹、装饰与死亡表演也冻结；系统减少动态效果的偏好同样生效。

设计参考 W3C 对闪烁频率、面积和亮度变化的说明；实现采取避免闪烁的方式，不表示已经取得无障碍认证或对所有人的医学安全作出保证。[W3C：Three Flashes or Below Threshold](https://www.w3.org/WAI/WCAG22/Understanding/three-flashes-or-below-threshold.html)
